# Official Source Map

Use this file to decide where to verify facts.

## 1. China equities / issuers

Primary sources:
- SSE (Shanghai Stock Exchange)
- SZSE (Shenzhen Stock Exchange)
- BSE (Beijing Stock Exchange)
- CNINFO / 巨潮资讯
- Issuer investor-relations site
- CSRC notices

Typical fact-to-source mapping:
- financial statements -> annual/interim/quarterly report
- dividend / buyback / placement / material events -> exchange announcement
- risk warning / delisting / regulatory measures -> exchange + CSRC
- index membership / methodology -> CSI or official index provider

## 2. China funds / ETFs

Primary sources:
- Fund manager official site
- Prospectus / fund contract / summary docs
- Annual, interim, quarterly reports
- Exchange disclosures for listed funds
- AMAC / CSRC when regulatory status matters

Typical fact-to-source mapping:
- investment objective / benchmark / fees -> prospectus or official factsheet
- top holdings / sector allocation -> latest fund report
- manager / custodian / contract amendment -> official announcements
- ETF creation-redemption / listing matters -> exchange and manager notices

## 3. US / global equities

Primary sources:
- SEC EDGAR
- issuer IR site
- official exchange releases when relevant

Typical fact-to-source mapping:
- revenue / EPS / segments / cash flow -> 10-K / 10-Q / 20-F / 6-K
- buybacks / dividends / material events -> 8-K / issuer release
- risk factors -> annual filing

## 4. US / global funds / ETFs

Primary sources:
- sponsor official site
- SEC filings
- prospectus / SAI / shareholder reports

Typical fact-to-source mapping:
- mandate / benchmark / fees -> prospectus
- holdings -> official holdings disclosure or report
- AUM / shares / flows -> sponsor materials if officially published

## 5. Red-flag checklist before answering

Check for these mistakes:
- Is the ticker/exchange correct?
- Is the source official?
- Is there a newer filing?
- Is the number audited or unaudited?
- Is the date clearly stated?
- Is the metric point-in-time or period-based?
- Are you comparing like-for-like periods?
- For funds: are holdings stale due to reporting lag?

## 6. If official source is unavailable

Say explicitly:
- official source not confirmed
- what was found instead
- why that is insufficient for a firm conclusion
- what exact document would be needed next
